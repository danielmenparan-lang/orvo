# ORVO24 — Cinematic Ad Production

## מה הסרטון כולל

6 סצנות AI עם דמויות אנושיות ותנועה אמיתית (image-to-video):

| # | סצנה | תיאור |
|---|------|--------|
| 1 | משרד | 8 אנשים עם לפטופים, אווירה כתומה, סגנון GTA |
| 2 | אורזת | הבחורה אורזת את התיק שלה |
| 3 | שואל | בחור: "אבל 4:30, למה את הולכת?" |
| 4 | עונה | היא: "הסוכן שלי מסיים לי את העבודה" |
| 5 | ספקן | מישהו: "אבל את לא יודעת לבנות סוכן" |
| 6 | טלפון | היא מראה orvo24.com על המסך |
