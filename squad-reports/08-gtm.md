# 08 — GTM Lead: 30-Day Go-to-Market for ORVO

**Product:** ORVO — vetted AI-agent marketplace (post → quote → chat → pay).  
**Beachhead niche:** Israeli SMBs who need WhatsApp / ops AI agents (restaurants, clinics, local services) + builders who ship those agents.  
**Live:** https://fantastic-eclair-0b2c66.netlify.app/  
**Window:** Day 0–30 (start: 2026-08-23).  
**North star (30d):** 40 waitlist/signups · 8 approved builders · 12 client requests · 3 paid or escrow-ready deals.

---

## 1. ICP (who we chase first)

### Primary client ICP — “WhatsApp-first SMB operator”
| Attribute | Detail |
|-----------|--------|
| Who | Owner / ops manager of restaurant, café, clinic, salon, delivery, or local service in Israel |
| Pain | Missed WhatsApp messages, manual order taking, FAQ spam, no night coverage |
| Budget signal | Already paying for POS / CRM / freelancer; can spend ₪2,000–₪15,000 for a working agent |
| Trigger | “I need a bot for WhatsApp / orders / appointments” — not “I need AGI” |
| Language | Hebrew primary; English OK for tech-forward founders |
| Disqualify | Enterprise RFP hunters, pure research/hobby prompts, “build me ChatGPT clone” |

### Secondary client ICP — “Solo founder / small tech team”
Needs a custom agent (support, lead qual, internal ops) but won’t hire full-time. English+Hebrew. Lower volume; higher AOV later.

### Builder ICP — “Agent shippers, not resume polishers”
| Attribute | Detail |
|-----------|--------|
| Who | Freelancers / indie hackers who have shipped WhatsApp (Twilio/WABA), n8n/Make, LangChain/OpenAI, or Israeli stack bots |
| Proof | Portfolio link, Loom of a live agent, or GitHub + client name |
| Motivation | Steady inbound jobs without cold DMs; platform takes fee later |
| Disqualify | “AI enthusiast” with no shipped work; agencies that only white-label ChatGPT |

**Wedge line (use everywhere):**  
*“Need a WhatsApp AI agent for your business? Post on ORVO. Vetted builders quote. Pay safe.”*  
Hebrew: *“צריכים סוכן AI לוואטסאפ לעסק? מפרסמים ב־ORVO. בונים מאומתים שולחים הצעות. משלמים בבטחה.”*

## 2. Offers (what we sell in month 1)

| Offer | Audience | Promise | Ask | Price / mechanic |
|-------|----------|---------|-----|------------------|
| **A. Founding waitlist (clients)** | SMB owners | Early access + first request prioritized to top builders | Email + 1-line need | Free; optional “I can pay this month” checkbox |

| **C. Founding builder cohort** | 10–15 builders | Badge + first dibs on Israel WhatsApp jobs | Apply + portfolio | Free; manual vet; 48h SLA |
| **D. Concierge pilot** | 3 design-partner SMBs | Done-with-you scoping call → posted ORVO request → hired builder | WhatsApp intro | ₪0 platform fee on first deal (founder absorbs) to prove loop |

**Do not offer in days 0–30:** marketplace discounts, open “anyone can bid,” agency white-label programs, or broad “AI consulting.”

## 4. 30-day plan

### Week 1 — Supply + proof (Days 0–7)
**Goal:** 8 builder applications → ≥5 approved · waitlist form live · 20 warm intros.

| Day | Actions |
|-----|---------|
| 0 | Publish LAUNCH-KIT assets; pin waitlist link; set ORVO admin review habit (2×/day) |
| 1–2 | DM 30 builders (portfolio filter); post LinkedIn #1 + X #1 (Hebrew primary) |
| 3–4 | Approve first cohort; ask each for 1 sample “agent type” they want to take |
| 5–7 | 15 WhatsApp intros to SMB owners; post IG carousel; collect 10 waitlist emails |

**Exit criteria:** ≥5 approved builders with skills tagged (WhatsApp / RAG / ops / support).

### Week 2 — Demand ignition (Days 8–14)
**Goal:** 8 client requests posted · 3 design-partner calls.

| Focus | Actions |
|-------|---------|
| Clients | Concierge: founder helps write the request brief for restaurants/clinics |
| Content | Ship SEO outline pages: “WhatsApp AI agent for restaurants” HE+EN |
| Social | Case-style posts (even if hypothetical → label as “example job”) |
| Ops | Match every open request to ≥2 builders within 48h |

**Exit criteria:** ≥8 requests · ≥1 quote accepted (even if payment still manual).

### Week 3 — Loop proof (Days 15–21)
**Goal:** 1–2 deals in progress · public social proof · referral ask.

| Focus | Actions |
|-------|---------|
| Delivery | Stay in chat; unblock scope; document before/after for content |
| Recruit | Second builder wave (skills gaps only) |
| Social | Customer quote or Loom (with permission) |
| Waitlist | Email #1: “3 example jobs live — post yours” |

**Exit criteria:** ≥1 project marked in progress · NPS-style ask to both sides.

### Week 4 — Amplify or cut (Days 22–30)
**Goal:** 40 total signups · decide paid channel · lock niche language.

| Focus | Actions |
|-------|---------|
| Metrics | Review funnel (see Metrics role): signup → request → quote → accept |
| Double-down | Whichever channel produced requests (likely WhatsApp + LinkedIn) |
| Kill | Channels with vanity engagement, zero applications/requests |
| Prep | SEO page #2; Hebrew FAQ; builder onboarding checklist |

**Exit criteria:** Written decision: stay on WhatsApp-SMB wedge or widen.

## 5. Waitlist mechanics

**Single form fields (keep short):**
1. Role: Client / Builder  
2. Email  
3. WhatsApp (optional, Israel preferred)  
4. One line: “What agent do you need?” or “What have you shipped?”  
5. Checkbox: “Ready in next 30 days”

**Lifecycle:**
- Instant auto-reply (HE+EN): “You’re on the ORVO founding list. We match manually this month.”
- Day 2: Clients get “Post your request” deep link; builders get Apply link  
- Weekly digest: 3 open job types + CTA  
- Promote waitlist members to full accounts as soon as they can self-serve

**Owner:** Founder reviews list daily; no CRM theater — Sheets/Supabase is enough.

---

## 6. Builder recruiting playbook

1. **Source list (50 names):** indie hackers IL, Upwork top WhatsApp freelancers, n8n/Make consultants, campus AI clubs grads with shipped demos.  
2. **Invite script (HE):** short — what ORVO is, vetting, no cold outreach, apply link, 48h review.  
3. **Vetting bar:** shipped agent proof OR paid client reference; reject vague “I use ChatGPT.”  
4. **Onboarding:** skills tags, rate band, languages (HE/EN), availability hours.  
5. **Activation:** send 1 matching open request within 24h of approval.  
6. **Retention:** weekly “new jobs” ping; founding badge; referral offer E.

**Cap month 1:** ~15 approved builders. Quality > fill.
