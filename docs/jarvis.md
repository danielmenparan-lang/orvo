# Jarvis — העוזר האישי של ORVO

Jarvis הוא העוזר האישי שלך (דניאל): מכיר אותך, מחובר ל־ORVO, ומתחיל **בהשכמה בבוקר**.

## שלב 1 — מעיר אותך

1. פתח בטלפון: [`jarvis.html`](../jarvis.html) (או אחרי דיפלוי: `/jarvis.html` באתר).
2. הגדר שעת השכמה.
3. לחץ **הפעל השכמה**.
4. השאר את הלשונית פתוחה / הוסף למסך הבית.
5. בשעה שבחרת: צליל + רטט + הודעה + **קול בעברית** עם תדריך ORVO.

לבדיקה מיידית: **הער אותי עכשיו**.

### מ־CLI (במחשב / סוכן)

```bash
node scripts/jarvis-wake.js status
node scripts/jarvis-wake.js briefing
node scripts/jarvis-wake.js now
```

### עריכת מה שצריך להשלים

קובץ: [`data/jarvis-priorities.json`](../data/jarvis-priorities.json)

Jarvis קורא את המשימות האלה בתדריך הבוקר.

## מה בא אחרי זה

| שלב | יכולת |
|-----|--------|
| 1 ✓ | השכמה + תדריך בוקר |
| 2 | חיבור Gmail — סיכום מיילים בבוקר |
| 3 | סטטוס ORVO חי (בקשות, בונים, תשלומים) |
| 4 | פעולות אמיתיות (טיוטות, תזכורות, follow-ups) |

## הערות

- ההשכמה עובדת כשהעמוד פתוח (מגבלת דפדפן — אין שעון מערכת בלי אפליקציה/שירות push).
- קול: דפדפן עם קול עברית (Chrome/Android בדרך כלל מצוין).
- אזור זמן: `Asia/Jerusalem` ב־`jarvis-config.js`.
