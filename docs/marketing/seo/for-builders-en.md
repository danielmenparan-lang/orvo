## Page outline (publish-ready)

### 1. Hero
- **Brand:** ORVO
- **Headline:** Build custom AI agents. Get hired on ORVO.
- **Lead:** Clients worldwide post custom AI agent jobs (WhatsApp, voice, CRM, automation, RAG). You apply once, get vetted, quote in USD, and get paid through ORVO — no cold DMs.
- **CTA:** Apply as a builder  
- **Secondary:** See how ORVO works

### 2. What jobs look like
| Vertical | Example scope | Typical band |
|----------|---------------|--------------|
| Chat / WhatsApp | FAQ, orders, kitchen/ops alerts | $500–$5,000+ |
| Clinic / salon | FAQ + booking rules + reminders | $800–$4,000+ |
| Ops / CRM | Lead qual → handoff → Sheets/CRM | $500–$3,000+ |

Product = **custom AI agents + vetted builders + global clients**. Vertical examples are acquisition, not geography locks.

### 3. Vetting (48h SLA)
1. Sign up with builder intent  
2. Bio (≥50 chars), skills, portfolio and/or Loom of a live agent  
3. Manual review — unvetted accounts don’t see jobs  
4. Approved → founding cohort badge + invites to matching requests  

**Disqualify:** “AI enthusiast” with no shipped work; ChatGPT-wrapper agencies only; generalists with no agent delivery proof.

### 4. How you get paid
- Clients accept a quote and fund through ORVO (Stripe path)  
- You deliver → client releases → payout to builder  
- Founding fee: **0%** early; target 10–12% later — always show net before accept  
- Do **not** take payment off-platform

### 5. Skills we want
- Meta WhatsApp Cloud API / WABA, voice/phone agents
- n8n / Make / webhook ops
- CRM / Sheets / POS hooks
- Optional: LangChain / OpenAI agents with clear delivery demos
- Local languages welcome in delivery; product UI is English

### 6. Liquidity honesty (builder-facing)
- Month 1 is **supply-first**: seed ~8–15 approved builders before advertising browse-all
- Concierge matching OK early; then open browse for approved builders
- Quote in **USD** for MVP

### 7. FAQ

**How does vetting work?**  
Manual portfolio/Loom review. Typical response within 48 hours.

**Do clients pay me directly?**  
No. Pay through ORVO so scope and payment stay on-platform.

**Is ORVO only WhatsApp?**  
WhatsApp is a strong vertical example. Clients also post voice, automation, CRM, and other custom agents.

**How do I get paid?**  
ORVO Stripe path after delivery/release steps.

**What should my application show?**  
Shipped agent work, preferred channels/verticals, timezone or countries you serve.

### 8. CTA repeat
Apply as a builder · Join founding cohort
