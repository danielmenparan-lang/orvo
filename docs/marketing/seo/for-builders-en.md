## Page outline (publish-ready)

### 1. Hero
- **Brand:** ORVO
- **Headline:** Build WhatsApp AI agents. Get hired on ORVO.
- **Lead:** Israeli SMBs post custom WhatsApp agent jobs (orders, bookings, FAQ, leads). You apply once, get vetted, quote in ILS bands, and get paid through ORVO — no cold DMs.
- **CTA:** Apply as a builder  
- **Secondary:** See how ORVO works

### 2. What jobs look like
| Vertical | Example scope | Typical AOV band |
|----------|---------------|------------------|
| Restaurant / café | Menu FAQ, takeaway orders, kitchen alert | ₪3,500–₪12,000 |
| Clinic / salon | FAQ + appointment rules + reminders | ₪6,500–₪12,000 |
| Local services | Lead qual → handoff → Sheets/CRM | ₪3,500–₪6,500 |

Beachhead = **WhatsApp + Hebrew UX + Israel SMB**. Other agent types waitlisted until niche liquidity clears.

### 3. Vetting (48h SLA)
1. Sign up with builder intent  
2. Bio (≥50 chars), skills, portfolio and/or Loom of a live agent  
3. Manual review — unvetted accounts don’t see jobs  
4. Approved → founding cohort badge + first dibs on Israel WhatsApp requests  

**Disqualify:** “AI enthusiast” with no shipped work; ChatGPT-wrapper agencies only; Upwork generalists with no WA/Hebrew proof.

### 4. How you get paid
- Clients accept a quote and fund through ORVO (Stripe path)  
- You deliver → client releases → payout to builder  
- Founding fee: **0%** early; target 10–12% later — always show net before accept  
- Do **not** take payment off-platform (WhatsApp / Bit side deals)

### 5. Skills we want
- Meta WhatsApp Cloud API / WABA (official vs unofficial awareness)
- Hebrew UX edge cases (RTL copy, slang, IL phone patterns)
- n8n / Make / webhook ops
- CRM / Sheets / POS hooks
- Optional: LangChain / OpenAI agents with clear delivery demos

### 6. Liquidity honesty (builder-facing)
- Month 1 is **supply-first**: we seed ~8–15 approved builders before advertising browse-all jobs
- Concierge matching: admin invites 1–3 builders per request
- Prefer ILS quote framing for IL clients

### 7. FAQ

**How does vetting work?**  
Manual portfolio/Loom review. Typical response within 48 hours.

**Do clients pay me directly?**  
No. Pay through ORVO so scope and payment stay on-platform.

**Is ORVO only WhatsApp?**  
That’s the beachhead. Expand after we clear liquidity in-niche.

**How do I get paid?**  
ORVO Stripe path after delivery/release steps.

**What should my application show?**  
Shipped WhatsApp or ops agent, Hebrew capability, preferred vertical (restaurant/clinic/leads).

### 8. CTA repeat
Apply as a builder · Join founding cohort
