# MONO Store

חנות איקומרס שחור־לבן עם באקנד (Express + SQLite), קטלוג מוצרים מנצחים וקישורי ספק מאליאקספרס.

## הרצה

```bash
cd shop
npm install
npm start
```

- חנות: http://localhost:4173  
- אדמין: http://localhost:4173/admin  

**Login אדמין:** `admin@mono.store` / `monoadmin123`

## מה בפנים

- 12 מוצרים מנצחים (טק / רכב / כושר / יופי / נסיעות)
- מחיר מכירה ב־₪ + עלות ספק ב־$ + קישור AliExpress לכל פריט
- עגלה, checkout, הזמנות במסד נתונים
- לוח ניהול: סטטיסטיקות, עריכת מחיר/מלאי, סטטוס הזמנות, קישורי הזמנה מספק

## זרימת דרופשיפינג

1. לקוח מזמין באתר  
2. באדמין רואים את ההזמנה + קישור AliExpress לכל פריט  
3. מזמינים מספק → מעדכנים סטטוס ל־`ordered_supplier` → `shipped`
