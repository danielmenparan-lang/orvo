# MONO — Travel & Outerwear

חנות שחור־לבן למזוודות, תיקים, כובעים וג'קטים. Express + SQLite, אדמין עם קישורי AliExpress.

## הרצה

```bash
cd shop
npm install
npm start
```

- חנות: http://localhost:4173  
- אדמין: http://localhost:4173/admin (`admin@mono.store` / `monoadmin123`)

## קטלוג

מזוודת cabin, סט 3 חלקים, דאפל סופ״ש, קרוסבודי, תיק גב, תיק מסמכים, פדורה, כובע מצחייה, באקט, בומבר, מעיל צמר, בייקר.
