# MONO Atelier

חנות איקומרס יוקרתית בשחור־לבן עם באקנד (Express + SQLite), קולקציית פרימיום וקישורי ספק מאליאקספרס.

## הרצה

```bash
cd shop
npm install
npm start
```

- חנות: http://localhost:4173  
- אדמין: http://localhost:4173/admin  

**Login אדמין:** `admin@mono.store` / `monoadmin123`

## יוקרה + פסיכולוגיה ב־UX

- עוגן מחיר (`compare_at`) + אחוז חיסכון
- מלאי מוגבל / מד־מחסור
- ספירה לאחור לסגירת מהדורה
- הוכחה חברתית חיה (רכישות מדומות לפי עיר)
- צופים עכשיו בעמוד מוצר
- נאדג׳ משלוח מתנה מעל ₪590
- אריזה דיסקרטית / 30 ימי החזרה / הבטחות אמון

## קטלוג

12 פריטי פרימיום: שעונים מכניים, מסכת LED, טוט, משקפי אצטט, משי, דיפיוזר, אספרסו נייד ועוד — עם קישור AliExpress לכל פריט באדמין.
